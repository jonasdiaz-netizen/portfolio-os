Google Sheet Sync

Beim Öffnen der App wird automatisch synchronisiert, sobald eine Web-App-URL hinterlegt ist. Ein manueller Sync ist jederzeit möglich.
Noch nicht eingerichtet. Trage deine private Apps-Script-URL und deinen privaten Sync-Schlüssel ein.

Ein Sync ersetzt immer nur die Sheet-Positionen. Manuelle Positionen und Immobilien werden nie gelöscht.

Einmalige Einrichtung

1. Öffne Google Apps Script und erstelle ein neues Projekt.
2. Füge die mitgelieferte Datei portfolio_os_google_sync.gs als Code ein.
3. Bereitstellen → Neue Bereitstellung → Web-App.
4. Ausführen als: Ich · Zugriff: Jeder.
5. Die erzeugte Web-App-URL hier oben einfügen.

Das Sheet selbst bleibt privat. Der Endpunkt liefert Daten nur mit dem in der App und im Script hinterlegten Geheimschlüssel.
